# Movie Recommendation System

A content-based movie recommendation system built with **Python, Pandas, NumPy, Scikit-learn, and Jupyter Notebook**.

The project preprocesses movie metadata, combines important movie attributes into a single text representation, converts the text into numerical vectors using **CountVectorizer**, and calculates movie-to-movie similarity using **cosine similarity**.

## Project Workflow

```text

          ↓

          ↓
```

## Notebook 1 — Data Preprocessing

`01_data_preprocessing.ipynb`

The preprocessing notebook performs the following steps:

1. Imports the required Python libraries.
2. Loads `Movies.csv` and `Credits.csv`.
3. Merges both datasets using the movie `title`.
4. Selects the following columns:
   - `movie_id`
   - `title`
   - `overview`
   - `genres`
   - `keywords`
   - `cast`
   - `crew`
5. Checks duplicates and dataset shape.
6. Removes records where `overview` is missing.
7. Converts JSON-like genre and keyword data into lists of names.
8. Extracts directors from the crew information.
9. Extracts the first three cast members.
10. Removes spaces from names/categories so they can be treated as individual tags.
11. Combines overview, genres, keywords, cast, and crew into a `tags` column.
12. Converts tags into lowercase text.
13. Saves the processed data as `cleaned.csv`.

## Notebook 2 — Model Training

`02_model_train.ipynb`

The recommendation model works using a **content-based filtering** approach.

### 1. Load Cleaned Data

The notebook reads:

```python
df = pd.read_csv("cleaned.csv")
```

### 2. Text Vectorization

`CountVectorizer` is used with a maximum of 5,000 features and English stop-word removal:

```python
cv = CountVectorizer(max_features=5000, stop_words="english")
```

The movie tags are transformed into numerical vectors.

### 3. Cosine Similarity

Cosine similarity is calculated between all movie vectors:

```python
similarity = cosine_similarity(vectors)
```

This produces a similarity matrix that represents how similar each movie is to every other movie based on their tags.

### 4. Recommendation Function

The notebook defines a `recommender()` function that accepts a list of movie titles, finds each movie in the dataset, sorts movies by similarity, and returns the most similar entries.

Example:

```python
recommender(["Avatar", "Titanic"])
```

The current implementation returns the first four similarity-ranked entries for each input movie, which includes the input movie itself because the movie has maximum similarity with itself.

### 5. Save Similarity Matrix

The similarity matrix is exported using Pickle:

```python
pickle.dump(similarity, open("similarity.pkl", "wb"))
```

This allows the calculated similarity matrix to be reused later instead of recalculating it every time.

## Recommendation Approach

This project uses **content-based filtering**.

Instead of relying on user ratings or collaborative user behavior, the system compares movie content using:

- Movie overview
- Genres
- Keywords
- Top 3 cast members
- Director

These attributes are combined into movie tags. The tags are then converted into vectors using `CountVectorizer`, and cosine similarity is used to measure similarity between movies.

## Current Limitations

- The recommendation function depends on exact movie-title matching after converting titles to lowercase.
- The current recommendation output includes the input movie itself because self-similarity is the highest similarity score.
- Recommendations are based on movie metadata rather than user ratings or viewing history.
- The notebooks require the input CSV files to be available locally.
- The saved `similarity.pkl` file can become large because it contains the complete movie-to-movie similarity matrix.
